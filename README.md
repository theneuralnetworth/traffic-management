# traffic-management

## Directories


- `traffic-management`: Contains the main code for traffic management.
- `ros_nodes`: Contains ROS nodes for traffic management.
- `config`: Contains configuration files for traffic management. Including SUMO map
- `config/sumo/map`: Contains the main SUMO simulation map.


### Legacy directories

Avoid adding new code to these directories. They are kept for legacy purposes only.

- `sumo_simulation`: Contains legacy code for SUMO simulation.
